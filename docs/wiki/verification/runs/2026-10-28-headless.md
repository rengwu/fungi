# Engine-only distribution and protocol migration

The selected engine-only checks passed. The user accepted a headless Fungi
distribution and assigned all UI implementations to other projects. This run
covers [sessions](../../features/sessions.md), [external helpers](../../features/interfaces.md),
[delivery primitives](../../features/delivery.md), [discovery](../../features/discovery.md)
and [installation](../../features/installation.md).

## Change and scope

Removed Wails, the webview/page bridge, JSON forms, UI examples, renderer
runtime installers and UI-specific drivers. External helpers use protocol 2;
engine packages use format 3. Direct UI launch commands are rejected with
migration guidance. Doctor now verifies atomic session storage and exclusive
locks. A helper that cannot execute produces a durable startup-failure result.

The selected verification comprises macOS source/package execution, Linux x64
execution without a userland/runtime, Windows x64 cross-compilation, local
bootstrap/update/rollback, and current documentation integrity. It does not
include hosted CI, public release, Windows execution, external UI projects,
new long-idle/sleep checks or real host callback consumption.

## Limits and cleanup

The earlier discovery test failed while the migration manual was still being
added; the completed source passed the race-enabled suite. Wiki checks also
caught a retired Wails anchor, which now points to a clearly historical section.
These intermediate failures do not qualify as passing evidence.

Windows runtime execution, Windows PowerShell bootstrap, hosted CI, public
publication/signing and consumer-machine setup remain untested for this build.
Callback uncertainty is regression-tested, but no new real end-of-turn callback
or all-harness resumption was claimed. External UI integrations must migrate
and verify their own rendering. Original protocol-1 sessions need their old
executable and assets.

No user installation, shell configuration or public release was changed. Test
helpers completed, the Linux test container/image were removed, and evidence
was copied into this wiki. Local test packages and isolated fixture sessions
remain under ignored dist/verification-output paths for inspection.
