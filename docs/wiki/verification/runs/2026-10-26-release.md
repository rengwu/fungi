# First public alpha distribution

**Distribution passed; the overall result remains Failed for one unexplained
intermittent Mac media probe failure.** Later passes do not erase that observation. Scope: [FEAT-installation](../../features/installation.md),
prebuilt public downloads, release automation and explicit alpha installation/updates.
The user made the repository public and authorized this distribution milestone.
Clean consumer-machine acceptance and long-idle harness qualification are separate.

## Build and workflow

Tag `v0.1.0-alpha.1` points to source
`239d70e3bbbd82e9b6a81fb32c20ff221a4387c7`. The
[release run](https://github.com/rengwu/fungi/actions/runs/40272022650) reuses
foundation verification with the actual release version. Only verified Mac
arm64, Windows amd64 and Ubuntu 22-built Linux amd64 archives are selected.
The Linux archive must pass unchanged on Ubuntu 24 before publication.
BUILD.json identifies the commit, clean-source state and both executable hashes.

The workflow creates a GitHub prerelease with three platform archives, SHA-256
sidecars and both installer scripts with their checksums. It does not rebuild
between verification and upload, mark a stable release, sign/notarize binaries,
change OS policy or alter update selection. Alphas require an explicit version.
Published bytes are immutable by project policy; corrections need a new version.

## Limits

This report does not qualify clean consumer-machine setup, security prompts,
signing/notarization, missing-WebView2 installation on a Windows machine without
it, physical Windows/Linux input, other architectures/OS versions or long Wails
sleep/wake. Linux checks explicitly exclude the accepted direct-media failure
and can record an unavailable WebGL context. These are not reported as successful
renders. Updating to the same public version verifies the download/revalidation
path; distinct-version switching and rollback use the existing packaged fixture.
The installers and test driver require neither persistent harness configuration
nor polling for a human.
