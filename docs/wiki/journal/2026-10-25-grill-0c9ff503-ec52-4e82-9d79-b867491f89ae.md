## Question 22

```text
Round: Wails: clean-machine setup
Question: When a supported machine lacks its system webview, what should Fungi's install command do?
Description (Markdown source):
Wails keeps Fungi's download small by using a browser engine outside the Fungi package. Our two Mac executables compressed to **5.9 MB**, before release packaging. That does **not** include a missing system runtime.

| Platform | Runtime used | Clean-machine consequence |
| --- | --- | --- |
| macOS | OS-provided WKWebView | No separate browser-runtime installation on supported macOS versions |
| Windows | Microsoft WebView2 Runtime | Detect it; some machines need Microsoft's runtime installed |
| Linux | GTK3 + WebKitGTK 4.1 and applicable runtime/media packages | Package availability varies by distro and desktop image |

Your first interview explicitly chose **no separate WebView2/WebKitGTK installation**. Later you asked for command installation and selected a Wails experiment. This question resolves that tension for a future Wails release. It does not install anything now.

Any runtime setup can need network access and, particularly on Linux, administrator privileges. Its download may be substantially larger than Fungi itself. A machine missing the runtime cannot get a guaranteed offline first launch from the small Fungi archive alone. Support still applies to explicitly tested OS/runtime environments.

**Storage isolation, restricted native APIs, and Linux media compatibility stay required engineering work.** None of these choices accepts the prototype's current gaps.

Sources: [Microsoft runtime distribution](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution), [Wails platform prerequisites](https://wails.io/docs/gettingstarted/installation/). The Wails page also lists build tools; Go, Node and compilers are not proposed end-user dependencies.
Recommendation: Allow optional, explicit runtime setup during installation. Reuse installed runtimes; when one is missing, explain the change and obtain the user's opt-in. Use official Microsoft or distro packages. Ordinary agent-invoked UI launches should only report a missing runtime, not install software. This best combines a small Fungi package with a practical clean-machine path.
Options: Allow explicit runtime setup in the install command (recommended) / Require preinstalled runtimes; Fungi only reports what is missing / Keep a separate, larger Electron edition for machines without system runtimes
Selected: Allow explicit runtime setup in the install command (recommended)
```
