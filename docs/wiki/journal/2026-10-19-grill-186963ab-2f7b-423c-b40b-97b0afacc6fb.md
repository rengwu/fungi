## Question 7

```text
Round: Fungi: renderer distribution
Question: May the default bundled renderer contain a proprietary engine?
Description (Markdown source):
Sciter is a compact candidate: the current Linux standalone runner inspected here is about 18.9 MB, but the engine has its own license and differs from browser DOM/CSS conventions. Servo and Chromium-based routes provide open-source alternatives. Ultralight's current terms restrict developer platforms unless separately licensed, so it is not a default candidate under ordinary SDK terms.

This choice concerns what Fungi distributes by default. Optional third-party capabilities can document their own licenses.

Sources: [Sciter engine EULA](https://gitlab.com/sciter-engine/sciter-js-sdk/-/blob/main/SCITER-ENGINE-EULA.md), [Ultralight terms, sections 4.2 and 4.9](https://ultralig.ht/terms/2026-08).
Recommendation: Use an open-source renderer in the default distribution, so rebuilding and extending Fungi does not depend on a proprietary engine agreement. Keep proprietary renderers possible as optional capabilities.
Options: Open-source renderer in the default distribution / A proprietary default is acceptable if redistribution is straightforward
Selected: Open-source renderer in the default distribution

```

## Question 8

```text
Round: Fungi: renderer distribution
Question: May Fungi automatically unpack its bundled renderer files when it first runs?
Description (Markdown source):
You have accepted one core executable with optional skill assets/helpers, plus bundled Chromium/Electron as a fallback. Chromium-based renderers normally need engine libraries, resource files and platform-specific helpers. One launchable download can contain these and unpack them into a private, versioned cache without an installer or internet download.

The distinction is one file to obtain and run versus literally one file existing at runtime. This question concerns Fungi's own bundled renderer; optional skill helpers are already accepted.

Sources: [CEF application layout](https://chromiumembedded.github.io/cef/general_usage#application-layout), [Electron packaging](https://www.electronjs.org/docs/latest/tutorial/application-distribution).
Recommendation: Allow automatic local extraction. Keep the download self-contained, work offline on first launch, require no setup command or administrator privileges, and reuse the matching cached runtime.
Options: Yes: one launchable download may unpack its bundled runtime / No extraction: the bundled renderer must stay inside the executable / Ship a portable folder/archive with the runtime already beside fungi
Selected: Yes: one launchable download may unpack its bundled runtime
Notes:
```
