# Fungi v0.1.0-alpha.3

Fungi’s macOS desktop window now shows the ghost icon in the Dock and the
Command-Tab app switcher. This update packages the icon with the 0.1 desktop
renderer and keeps the same CLI, helper protocol, and saved sessions.

## Update an existing installation

```sh
fungi update --version v0.1.0-alpha.3
```

The next Fungi window you open will use the new icon. Windows already open
continue running the version that launched them.

## Install

On Apple Silicon with macOS 26 or later, or Ubuntu 22.04/24.04 x64, run

```sh
curl -fsSL https://github.com/rengwu/fungi/releases/download/v0.1.0-alpha.3/install.sh | sh -s -- --version v0.1.0-alpha.3 && export PATH="$HOME/.fungi/bin:$PATH"
```

On Windows x64, run this in PowerShell

```powershell
Invoke-WebRequest -UseBasicParsing https://github.com/rengwu/fungi/releases/download/v0.1.0-alpha.3/install.ps1 -OutFile "$env:TEMP/fungi-install.ps1"; & "$env:TEMP/fungi-install.ps1" -Version v0.1.0-alpha.3
```

The installer verifies the platform archive’s SHA-256 checksum. Run
`fungi doctor` to check your runtime. These alpha downloads are unsigned and
unnotarized. See the [desktop platform notes](https://github.com/rengwu/fungi/blob/v0.1.0-alpha.3/docs/wiki/platforms.md)
for runtime requirements and known media limitations.
