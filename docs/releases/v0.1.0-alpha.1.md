# Fungi v0.1.0-alpha.1

First public alpha for skill authors. Fungi runs local HTML/CSS/JS interfaces
in a Wails window, collects JSON and file artifacts, and returns them to the
calling agent. It includes offline API documentation and small working examples.
The Go CLI uses the system webview; no Electron, Node, npm or Go installation
is needed to run it.

## Downloads

Choose one package and keep its extracted folder together:

| Machine | Archive | System runtime |
| --- | --- | --- |
| macOS 26+ on Apple Silicon | fungi-darwin-arm64.tar.gz | macOS WKWebView |
| Windows x64 | fungi-windows-amd64.zip | Microsoft WebView2 |
| Ubuntu 22.04/24.04 x64 | fungi-linux-amd64.tar.gz | GTK3 / WebKitGTK 4.1 |

Every archive has a `.sha256` sidecar. The Linux archive is built on Ubuntu
22.04 and tested unchanged on 24.04. Intel Macs and Windows/Linux ARM are not
included. BUILD.json identifies the source commit and executable hashes.

## Install

Mac or Ubuntu:

```sh
curl -fsSL https://github.com/rengwu/fungi/releases/download/v0.1.0-alpha.1/install.sh | sh -s -- --version v0.1.0-alpha.1 && export PATH="$HOME/.fungi/bin:$PATH"
```

Add the PATH entry to your shell configuration for new terminals. Windows PowerShell:

```powershell
Invoke-WebRequest -UseBasicParsing https://github.com/rengwu/fungi/releases/download/v0.1.0-alpha.1/install.ps1 -OutFile "$env:TEMP/fungi-install.ps1"; & "$env:TEMP/fungi-install.ps1" -Version v0.1.0-alpha.1
```

The scripts download one package, check its checksum and create a managed
per-user installation. If a runtime is missing, setup stops with instructions.
Opt into runtime installation explicitly with `--setup-runtime` (Ubuntu) or
`-SetupRuntime` (Windows). No administrator permission is needed for Fungi's
own files; system runtime setup can require it.

Run `fungi help`, `fungi help examples` and `fungi describe examples` to begin.
For alpha updates, use `fungi update --version VERSION` with the exact published
alpha version. Plain `fungi update` selects the latest stable release; none
exists yet. Managed installs support rollback and prune.

## Alpha limits

- Binaries are not publisher-signed or notarized. OS policy may block them;
  neither Fungi nor its installer changes that policy.
- Hosted rendering/install/update checks are not clean consumer-machine or
  physical Windows/Linux input qualification. Missing WebView2 installation on
  a Windows machine without the runtime and long Wails sleep/wake remain untested.
- Linux direct local audio/video URLs can fail. WebGL depends on the machine;
  virtual Linux CI records unavailable contexts separately.
- Skill pages are trusted code with native access. Browser storage isolation
  is best effort. Crash recovery is explicit; optional drafts support reopening.
- Automatic notification depends on the agent harness. Inspect the receipt;
  use manual “done” and collect once when automatic delivery is unavailable.
  Never poll for a person to finish.

This release is intended for early feedback, with no stable compatibility promise.

## Post-publication check

The first hosted Mac public-download run passed installation, updating and 20
rendering checks, but its media metadata/seek probe failed. The same public
archive passed all 21 checks on the maintainer Mac, plus eight diagnostic
repetitions. A hosted Mac follow-up also passed all 21 checks with the same
archive. The original failure remains unexplained; media behavior should be
treated as provisional in this alpha. The Mac helper targets macOS 26.0; older
macOS versions are not supported by this archive.

Public installer and updater checks succeeded on Mac, Windows and both Ubuntu
baselines. [Verification record](https://github.com/rengwu/fungi/blob/main/docs/wiki/verification/runs/2026-10-26-release.md).
