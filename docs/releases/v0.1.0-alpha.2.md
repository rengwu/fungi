# Fungi v0.1.0-alpha.2

Terminal help now displays clean headings, aligned columns and wrapped prose.
Code examples and long commands stay intact for copying. All eight help topics
still work offline, with no pager, renderer or extra dependencies. The packaged
Markdown manual and JSON `describe` API remain available.

Installation instructions now use one copy-paste line per shell, with current
terminal PATH setup included on Mac/Linux.

## Update

```sh
fungi update --version v0.1.0-alpha.2
```

Run `fungi help` to see the new formatting.

## Install

Mac Apple Silicon (macOS 26+) or Ubuntu 22.04/24.04 x64:

```sh
curl -fsSL https://github.com/rengwu/fungi/releases/download/v0.1.0-alpha.2/install.sh | sh -s -- --version v0.1.0-alpha.2 && export PATH="$HOME/.fungi/bin:$PATH"
```

Add the PATH entry to your shell configuration to keep it in new terminals.
Windows x64, using PowerShell:

```powershell
Invoke-WebRequest -UseBasicParsing https://github.com/rengwu/fungi/releases/download/v0.1.0-alpha.2/install.ps1 -OutFile "$env:TEMP/fungi-install.ps1"; & "$env:TEMP/fungi-install.ps1" -Version v0.1.0-alpha.2
```

Run `fungi doctor` to check the runtime. Each installer downloads one platform
archive and verifies its checksum. Runtime installation remains opt-in via
`--setup-runtime` (Ubuntu) or `-SetupRuntime` (Windows).

## Alpha limits

These downloads are unsigned and unnotarized. Mac packages require macOS 26+
and Apple Silicon; Windows/Linux packages are x64. Clean consumer-machine
qualification, older OS targets and long sleep/wake are still separate work.

Rendering behavior is unchanged: Linux direct local media can fail, and an
intermittent Mac media metadata/seek probe failure remains unexplained despite
passing follow-ups. Pages retain native access; storage isolation is best effort.
See the [platform notes](https://github.com/rengwu/fungi/blob/main/docs/wiki/platforms.md).
